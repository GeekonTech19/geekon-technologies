# Geekon Technologies Website

React + Vite + TypeScript corporate website starter for Geekon Technologies.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The Geekon logo supplied for this project is in `public/got-logo.png`.

## Render

Create a Render Static Site connected to this repository.

Build command:
`npm install && npm run build`

Publish directory:
`dist`
